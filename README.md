# TALAAN v2 — SSG Attendance Portal

Official attendance monitoring system of the LVCC Caloocan Supreme Student Government.

## Technology
- Frontend: HTML, CSS, JavaScript
- Hosting: Firebase Hosting
- Authentication and Database: Firebase Authentication and Cloud Firestore
- Backend API: Cloudflare Workers

## Development Status
Step 3 — Staging preparation and integration testing.

## Security
Production credentials, Firebase service account keys, and private configuration files must never be committed to this repository.

## Deployment
Firebase Hosting will serve the application. GitHub is used for source control only.
